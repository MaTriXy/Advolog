# התקנה ב־Claude — מדריך מלא

<!-- Canonical Hebrew; the site carries this content with an English toggle.

יש שתי דרכים טובות להריץ את CareHub Open ב־Claude. לא צריך לבחור מראש נכון: אפשר להתחיל בקלה ולעבור אחר כך, הרשומות עוברות איתך.

**דרך א — פרויקט באתר (claude.ai):** מתאימה לכולם, עובדת גם בנייד. השיחה מכינה כל שמירה בשבילך, קובץ אחד בכל פעם, או שהלוח שומר בשבילך.
**דרך ב — תיקייה במחשב (Claude Code / Cowork):** למי שנוח לו עם אפליקציה שולחנית. העוזרת כותבת את הרשומות ישירות לתיקייה בעצמה — הכי חלק שיש.

---

## דרך א — פרויקט ב־claude.ai

1. נכנסים ל־claude.ai ומתחברים לחשבון (חינמי מספיק להתחלה).
2. בתפריט הצד: **Projects** ← **New project**. שם חופשי — למשל «התיק הרפואי שלי».
3. פותחים את חלון ההגדרות של הפרויקט ומאתרים את אזור ההנחיות (Instructions / הוראות פרויקט).
4. מדביקים שם את כל התוכן של `package/prompts/core-map.md`.
   [צילום מסך: מסך פרויקט חדש עם שדה ההנחיות מסומן]
5. באזור הקבצים של הפרויקט (Project knowledge) מעלים את הקבצים מ־`package/prompts/skills/` ואת `package/he/` (שלושת הקבצים). אפשר לגרור את כולם יחד.
   [צילום מסך: העלאת קבצים לפרויקט]
6. פותחים שיחה חדשה בתוך הפרויקט וכותבים שלום — או פשוט מתחילים לספר. זהו. הריאיון יוביל משם, שאלה אחת בכל פעם.

**חלופה בלי שום התקנה:** לא רוצים פרויקט? פותחים שיחה רגילה ומדביקים את פרומפט הפתיחה מ־`package/starter/starter-prompt.md` (או מכפתור ההעתקה באתר). זו גרסה קלה ושלמה — בלי קבצים בכלל.

**איפה הרשומות?** בדרך הזאת קובצי הרשומות נשמרים אצלך במחשב, בתיקייה אחת שאת/ה בוחר/ת, והשיחה מלווה כל שמירה — או שפותחים את `dashboard.html` מתוך אותה תיקייה והוא מכניס את העדכונים בלחיצה (המדריך המלא: `dashboard-guide.md`). בנייד, כשאין תיקייה נוחה, אפשר לנהל את הגרעין בתוך השיחה ולהעביר לקבצים כשמגיעים למחשב.

## דרך ב — תיקייה במחשב (Claude Code / Cowork)

1. מתקינים את אפליקציית Claude למחשב (או את Claude Code) ומתחברים.
2. מחלצים את חבילת ההורדה אם עוד לא (חשוב: לחלץ באמת — לחיצה ימנית ← «חלץ הכול» בווינדוס, לחיצה כפולה במק. אם רואים את הקבצים בתוך חלון של תוכנת מכווץ — זה עדיין בתוך ה־zip).
3. שמים את תיקיית `package` איפה שנוח (מסמכים, למשל) — אפשר לשנות לה שם.
4. פותחים את Claude על התיקייה הזאת (Open folder / עבודה על תיקייה).
5. כותבים שלום. העוזרת קוראת את המפה בעצמה, והריאיון מתחיל. מהרגע הזה היא גם שומרת את הרשומות ישירות בתיקייה — כל שמירה מוכרזת בשורה רגועה אחת.

**יחידות מיומנות:** בסביבה הזאת אפשר גם «להתקין» יחידות כך שיופעלו אוטומטית. אין צורך לעשות את זה מראש: כשיחידה תהיה רלוונטית, העוזרת תציע ותלווה את ההתקנה צעד־צעד, ותוודא כל צעד לפני הבא.

## שיחה חדשה בתוך הפרויקט (לרגע שהעוזרת מציעה «שיחה חדשה»)

שיחות ארוכות נעשות כבדות, ומדי פעם העוזרת תציע לפתוח דף נקי. איך עושים את זה בלי לאבד כלום:

- **באתר:** נכנסים לפרויקט (Projects ← השם שבחרת) ← **New chat** בתוך הפרויקט. השיחה החדשה מכירה את ההנחיות והקבצים של הפרויקט.
- **במחשב:** שיחה חדשה על אותה תיקייה. העוזרת קוראת את הרשומות ונכנסת לעניינים לבד.
- בשני המקרים, מילה אחת מספיקה בפתיחה: «תתעדכני» — והיא תספר איפה עמדנו.

## פרטיות בחשבון Claude — הליך קצר

ההצעה לעבור על זה מגיעה כבר בהתקנה, וחוזרת פעם אחת לפני הייצוא הראשון. שתי דקות:

1. נכנסים להגדרות החשבון (Settings) ← מחפשים את אזור הפרטיות או Data.
2. **שימוש בשיחות לאימון המודל:** אם מופיעה בחשבון שלך אפשרות כזו — מחליטים בה במודע. מי שמעדיף שהשיחות לא ישמשו לאימון, מכבה אותה. בחלק מסוגי החשבונות ברירת המחדל שונה, והמסכים משתנים מדי פעם — אם ההגדרה לא במקום המתואר, לחפש «privacy» או «data» בהגדרות. המדריך הזה מנחה ולא מבטיח: מה שקובע הוא מה שמופיע אצלך.
3. שווה להכיר גם את משך שמירת השיחות ואת אפשרות המחיקה — לפי מדיניות הפלטפורמה כפי שמוצגת בחשבון.
4. תזכורת קבועה, בלי קשר להגדרות: הכלי לעולם לא מבקש תעודת זהות, כתובת מדויקת או שם מלא מעבר למה שבחרת לרשום — וכל ייצוא עובר קודם את רשימת הבדיקה.

## מתכוני אוטומציה (שכבה מתחלפת — לבדוק מדי פעם)

> **הסימון הזה חשוב:** תכונות תזמון של פלטפורמות הן החלק הכי פחות יציב בחבילה. המתכונים כאן נבדקים מחדש במחזוריות, וליד כל אחד עומד **תאום ידני** — פרומפט להדבקה שעושה בדיוק את אותו הדבר, בלי שום תלות בתכונה. התאום הוא המסלול המובטח; התזמון הוא נוחות.

כל אוטומציה מוצעת בשיחה בכרטיס ברור (מה היא עושה, מה קוראת, מה כותבת, איך מכבים) ולא קיימת בלי הסכמה מפורשת. הפלט תמיד נוחת בתיבת הקליטה כהצעה — שום דבר לא נכנס לרשומות בלי אישור.

- **סריקת מחקר וקהילות** — תאום ידני: `package/prompts/twins/sweep-twin.md`. תזמון: אם בסביבת Claude שלך יש תכונת משימות מתוזמנות, יוצרים משימה חודשית שמדביקה את התאום. אין תכונה כזו בחשבון? מדביקים את התאום ידנית פעם בחודש — אותה תוצאה בדיוק.
- **בדיקת טריות התיקייה** — תאום ידני: `package/prompts/twins/freshness-twin.md`. בדרך ב זה קורה ממילא בכל «תתעדכני»; התזמון מיותר לרוב.
- **בדיקת יכולות חודשית** — תאום ידני: `package/prompts/twins/capabilities-twin.md`. כללי המקורות שלה קשיחים (תיעוד רשמי בלבד) ו«אין חדש החודש» היא תשובה שלמה.
- **סיכום סשן / מסירה** — תאום ידני: `package/prompts/twins/wrapup-twin.md`; מופעל ידנית בסוף ישיבה ארוכה, או כשהעוזרת מציעה.
