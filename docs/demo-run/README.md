# הרצת הדמו של עמוד הבית — התיעוד המלא

הקטע שמופיע בעמוד הבית תחת «דוגמה» הוא תמליל אמיתי: הרצה של הערכה כלשונה (המפה, יחידות המיומנות, קאנון הקול) על **נועה — דמות בדיקה מומצאת** שמשמשת את הפרויקט מאז שלב התכנון. שום פרט כאן לא מתאר אדם אמיתי.

- `transcript-he.md` — התמליל המלא, מילה במילה (העמוד מציג קטע ממנו).
- `records/` — קובצי הרשומות שההרצה באמת כתבה, כפי שנכתבו.
- `method.md` — איך ההרצה בוצעה, כולל הסטיות מהתסריט ומה נשאר לא־פתור בכוונה.

ההרצה מתועדת כדי שהדוגמה תישאר כנה: כשההנחיות משתנות, מריצים מחדש ומחליפים — לא מלטשים ביד.

*(English: the homepage demo is an excerpt of a real run of the shipped suite on Noa, the project's invented canonical test persona. Full transcript, the run's actual record files, and the method note live here. Nothing describes a real person.)*
